## Что нужно для полностью самостоятельного запуска

Содержимого ZIP достаточно **для установки и проверки исходной переносимой MCP-сборки** в Windows с Python. Для **реального облачного подключения** дополнительно нужны: официальный полный `tunnel-client.exe`, доступ к интернету, Tunnel ID, runtime API key с Tunnels Read + Use, связь туннеля с правильным ChatGPT workspace и разрешение аккаунта создавать custom MCP connection. Это **внешние prerequisites**, которые нельзя легально и безопасно включать в ZIP с чужими секретами.

В соответствии с [текущей справкой OpenAI](https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt), полный custom MCP доступен Business и Enterprise/Edu при надлежащей роли; для Pro есть ограничения, а Plus не может рассматриваться как гарантированно поддерживающий самостоятельное создание custom MCP. Если нужная кнопка в ChatGPT отсутствует, это блокер прав, а не неполнота ZIP.

## Уровень доказательности

Это **офлайн-интеграционные проверки и проверка документации**, а не E2E-подтверждение новой Windows-машины или доступности сервисов OpenAI в конкретном аккаунте. Изолированные тесты не подтверждают работоспособность сети, браузера, существующего туннеля и аккаунта пользователя. Для финальной приёмки выполните шаги 4–9 [основной инструкции](TRANSFER_TO_NEW_PC_RU.md) на целевом ПК и убедитесь, что реальный `list_workspaces` проходит через туннель.
