## Что НЕ проверено и чего ZIP не делает

- Настоящая регистрация custom MCP в **другом ChatGPT-аккаунте**: нужны личные Platform credentials, права на custom MCP и отдельно созданный Tunnel ID. Архивы нельзя считать автоматически импортируемыми в ChatGPT.
- Доставка нового веб-чата, браузерная отправка, `message_saved` и `REPORT_ACKED` на чужом аккаунте не проверялись. Тесты безопасно избегают открытия/отправки реальных чатов.
- `Chain3` в доверенном режиме не готова до защищённого, независимого P085 Windows broker и приёмки цепочки Chain2. Выбор `trusted` в конфиге не выдаёт полномочия.
- Точное потребление токенов через веб-ChatGPT не измерялось.
- Публикация бинарных архивов на GitHub проверена через metadata/blob SHA; реальная загрузка из произвольной сети пользователя зависит от его соединения и фильтров.

**Итог:** переносимый набор пригоден для локальной тестовой установки. Полноценная автономная работа и импорт как готовых зарегистрированных приложений не подтверждены. Для повторения испытаний из корня полного ZIP: `py -3 scripts/test-distribution.py`, `py -3 scripts/verify-portable-install.py --test-powershell`.
