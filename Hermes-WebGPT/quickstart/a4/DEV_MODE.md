# Hermes A4 — DEV-режим без стоп-фактора при разработке

## Как запустить

Из корня установленного проекта на Windows 10/11 двойным щелчком:

**`Start-Hermes-All.cmd`** — основной запуск, теперь временно DEV по умолчанию.

Альтернатива: `Start-Hermes-DEV.cmd` — тот же явный DEV-запуск.

Для возврата строгих проверок: `Start-Hermes-STRICT.cmd` (либо переменная окружения `HERMES_A4_STRICT=1` при запуске обычного файла).

Либо открыть `Setup-Hermes-A4.cmd` и нажать **«DEV: запустить Hermes без стоп-фактора A4»** внизу мастера.

Эквивалент из консоли:

```powershell
powershell.exe -NoProfile -File .\quickstart\start.ps1 -DevMode
```

## Что меняется

- Пропускается только дополнительная A4-проверка `settings-a4.json` → «нельзя запускать, пока не создан защищённый MCP».
- DEV — **режим по умолчанию для текущего A4 рабочего запуска** (`Start-Hermes-All.cmd`), без изменения постоянных параметров Windows. `Start-Hermes-STRICT.cmd` сохраняет строгое поведение и не требует менять файлы.
- Проверки уже работающих процессов, предотвращение повторного запуска, портов, readiness и настроенного Telegram/Tunnel **не отключаются**. DEV не создаёт секреты и не расширяет права Windows.
- Выбранный в GUI `read_only` **не ограничивает** существующий 28-инструментальный MCP в DEV-режиме. Используются реальные текущие настройки и доступы, которые уже были предоставлены этому MCP. Не подключайте его к публичному недоверенному Tunnel.

## Быстрая проверка, не запускающая службы

```powershell
powershell.exe -NoProfile -File .\quickstart\start.ps1 -GateCheckOnly -DevMode
```

Ожидаемый признак — `A4_GATE_OK`. Без `-DevMode` при наличии A4-настроек тот же gate-check возвращает код 2.

## Что НЕ является стоп-фактором для DEV

Недостающая независимая production-приёмка A5, отсутствие OS-sandbox полного доступа и незавершённый защищённый observer Tunnel больше **не блокируют локальный запуск уже подготовленного Hermes** через DEV-вход.

Что по-прежнему нужно для работы с нуля: установленные MCP/Tunnel/Relay/Gateway и расширение Яндекс Браузера, действительные ключи, работающая сеть. DEV не восполняет отсутствующие файлы и не гарантирует Telegram ↔ ChatGPT E2E.
