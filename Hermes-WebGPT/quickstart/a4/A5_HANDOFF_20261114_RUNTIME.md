## Текущая граница готовности

Изменения здесь являются **частью цепочки установки**, не финальным установщиком. ZIP содержит только Python-модули Relay/Gateway, не включает расширение Яндекс Браузера, MCP Host, Tunnel, официальный Hermes Agent Core, настройки сессионной оркестрации и сквозные медиа-сценарии.

**Запрещено утверждать** о работоспособности полного E2E или самостоятельном первом запуске из клона: часть файлов runtime отсутствует в GitHub; реальный режим полного доступа на уровне OS/broker не изолирован; Docker/чистая Windows VM и реальные подтверждения пользователя ещё не пройдены.

## Что проверить A5 независимо

1. Пересчитать SHA256 24 модулей и ZIP, исследовать полный исходный код и динамические импорты, проверить отсутствие приватных данных; только после этого рассматривать публикацию.
2. Проверить в чистой Windows 10 и 11: `git clone` → двойной щелчок → мастер → обе модели разрешений → авторизация и запуск всех служб без консоли.
3. Проверить отрицательные E2E: read-only отклоняет записи/исполнение/изменение внешних систем и не допускает обход через альтернативные MCP-профили/туннели.
4. Отдельно тестировать «Полный доступ» только с реально выданным owner grant в выбранной папке и OS-изоляцией; отсутствие такой защиты — **release blocker**.
5. Смоделировать: повреждение архива, замену хеша, symlink/junction, отказ от согласия, два параллельных установщика, перезагрузку Windows во время установки, восстановление/rollback, обрыв Tunnel, отсутствие ключа.
6. Реальный Telegram → Яндекс Браузер → ChatGPT Web → Telegram: текст, изображения, файлы, длительная генерация, отсутствие дублей.
7. Выдать независимый вердикт с точными командами, returncode, логами и блокерами; Draft PR не мержить до 100% подтверждения.

**Мой вывод по A4:** безопасный локальный кандидат собрать и проверить возможно, но production acceptance всё ещё не достигнута. Не трактовать прохождение тестов на рабочем ноутбуке как доказательство чистой установки.
