# Избирательное восстановление черновика Hermes

Снимок двух транспортных файлов, проверенный и синхронизированный с рабочей
распакованной копией Web Companion 0.9.7 10.11.2026. Это дополнение к существующей
установке, не самостоятельное расширение и не замена старых ZIP в репозитории.

`web_manual_input` возникает при непустом редакторе. ChatGPT может восстановить
черновик предыдущей попытки в новой вкладке. Неизвестный пользовательский текст
по-прежнему блокирует отправку. Разрешается заменить только точное совпадение
SHA-256/длины с сохранённым собственным запросом, терминально заблокированным
ДО Send. Проверяются lease, documentId, окно, неактивная вкладка, claimed и
отсутствие привязанного серверного tab. Старая попытка никогда не повторяется.
Полный старый черновик сначала сохраняется и перечитывается в локальном
карантине с noReplay. Изменение владельца, текста, страницы, видимости или
пользовательский ввод во время восстановления отменяют замену.

Также сохранено актуальное исправление ACK: intent POST выполняется один раз,
затем до трёх read-only проверок подтверждают его фиксацию перед единственным
click. После последнего async предупреждения перед click повторно проверяются
редактор, точный текст, адрес, аккаунт и кнопка.

## Проверка

```sh
node Hermes-WebGPT/patches/manual-draft-20261110/test_owned_draft.cjs
```

25/25 новых сценариев; ещё 16 bootstrap и 20 queue-wake регрессий прошли в
Windows-проекте. Штатная публикация дополнительно проверила 13 auto-reload и
48 editor assertions. Native Edge MV3: три сценария с fake HTTP и управляемой
DOM-страницей, без реальных отправок в ChatGPT/Telegram:

| Сценарий | Исход | Send intent | Результат |
|---|---|---:|---:|
| Известный черновик до Send | done, карантин сохранён | 1 | 1 |
| Ручной текст | manual_input, текст сохранён | 0 | 0 |
| Старая uncertain-попытка | manual_input, fence сохранён | 0 | 0 |

Стенд требует Playwright и установленный Edge. Он запускается из лабораторной
папки внутри Hermes-WebGPT/planning и использует core.js существующей установки.
Страница и её visibility специально управляются стендом. Это не живой E2E.
